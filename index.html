💬 Le vestiaire

CoachBot · aide instantanée

Clique sur 🎙️ Parler, ou maintiens Espace quand tu es dans l’onglet Discussions (sans être dans le champ de texte).

Le CoachBot peut discuter et répondre à des questions grâce à une base de réponses intégrée : pas besoin de compte ni d’Internet. Les conversations restent sur cet ordinateur. Cette version n’utilise pas encore une IA générative en ligne.

Version réelle : les messages entre utilisateurs et les comptes sécurisés demandent un serveur, une base de données et des protections contre le harcèlement et le spam. Ce prototype ne collecte pas de vrais mots de passe.
